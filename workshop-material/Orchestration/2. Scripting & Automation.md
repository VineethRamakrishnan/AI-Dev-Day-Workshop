
Scripting & Automation
Claude Code isn't just an interactive assistant — it can also act as a scriptable Unix tool. With claude -p, you can run Claude from bash scripts, CI pipelines, and automation workflows without starting a session.

Non-Interactive Mode
The -p (print) flag runs a query, prints the response, and exits. No session is saved.

claude -p "Explain what this project does"

Output Formats
Flag	Output
(none)	Plain text
--output-format json	Structured JSON
--output-format stream-json --verbose	Streaming JSON (real-time)
Try It: Analyze the Shopping Cart
Run these commands in the terminal (not inside a Claude session):

Step 1 — Get a project summary as JSON:

claude -p "List all API endpoints in this project with their HTTP methods" --output-format json

Step 2 — Check for missing error handling:

claude -p "Check backend/routes/ for any endpoints that don't validate input. List the file and function name for each."

Observe: Claude analyzes the code and exits — no session, no follow-up needed. The output can be piped to other tools or saved to a file.

Fan-Out Pattern
Process many files in parallel by looping claude -p over a list. Each invocation runs independently.

Workflow
Have Claude list the files that need work
Test your prompt on 2–3 files
Refine based on what goes wrong
Run at scale
Try It: Add Input Validation to All Route Files
Let's use the fan-out pattern to add input validation to all backend route files in batch. Run these commands in the terminal (not inside a Claude session):

Step 1 — List the route files:

find backend/routes -name "*.py" -not -name "__init__.py"

Step 2 — Test on one file first:

claude -p "Review backend/routes/cart.py and add input validation to any endpoint that doesn't validate required fields. Return proper 400 errors for invalid input." --allowedTools "Read,Edit"

Step 3 — Run on all route files:

for file in $(find backend/routes -name "*.py" -not -name "__init__.py"); do
  echo "Processing: $file"
  claude -p "Review $file and add input validation to any endpoint that doesn't validate required fields. Return proper 400 errors for invalid input." --allowedTools "Read,Edit"
done

Observe: Each file is processed independently. The --allowedTools flag restricts Claude to only reading and editing — no running commands or creating new files.

Step 4 — Verify the changes:

git diff --stat

---
Key Takeaways

* claude -p makes Claude a scriptable tool — use it in CI, pre-commit hooks, and batch scripts
* Fan-out processes many files independently in parallel
* --allowedTools restricts what Claude can do in non-interactive mode
* --output-format json produces structured output for piping to other tools
